# Website Refinement Rules

This project is already built.

Do not redesign the website.

Focus only on:
- spacing refinement
- typography hierarchy
- alignment consistency
- responsiveness
- premium visual polish
- animation refinement
- UI consistency

Maintain:
- existing branding
- existing layout structure
- existing sections
- existing content

Avoid:
- unnecessary redesigns
- SaaS/dashboard styling
- excessive effects
- random UI additions

Keep the website clean, premium, restrained, and production-ready.
