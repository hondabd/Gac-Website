# Design System & UI Direction

# Core Design Philosophy

This website is already built.

The objective is NOT redesign.

The objective is to refine and polish the existing website to premium international automotive website standards.

The website should feel:

- premium
- elegant
- cinematic
- minimal
- spacious
- refined
- modern automotive
- high-end
- balanced
- confident

The design language should resemble modern premium automotive brands such as:

- Mercedes-Benz
- Lexus
- Genesis
- Lucid Motors
- Zeekr
- Volvo
- NIO
- Range Rover

Avoid:
- startup/SaaS styling
- cyberpunk styling
- overly futuristic UI
- flashy visual effects
- trendy overdesigned layouts

The website should feel timeless and restrained.

---

# Visual Tone

The UI should feel:

- calm
- luxurious
- spacious
- cinematic
- refined
- image-focused

Luxury websites rely on:
- spacing
- typography
- visual rhythm
- restraint
- composition

NOT excessive effects.

Avoid:
- clutter
- visual noise
- oversized shadows
- aggressive animations
- excessive gradients
- glowing effects
- crowded sections

---

# Layout System

## Containers

Use consistent container widths globally.

Maintain:
- balanced layouts
- generous spacing
- strong visual rhythm

Avoid:
- inconsistent margins
- cramped layouts
- stretched content

---

## Section Spacing

Desktop:
- large breathing room between sections
- generous vertical spacing

Tablet:
- slightly reduced spacing

Mobile:
- preserve breathing room proportionally

Every section should feel visually separated and breathable.

---

# Typography System

Typography should feel elegant and restrained.

## Headings

- strong hierarchy
- balanced spacing
- clean line heights
- refined scale
- avoid oversized typography

## Paragraphs

- readable line length
- comfortable line spacing
- balanced spacing from headings

Avoid:
- excessive bold usage
- compressed typography
- oversized text blocks

Typography should feel premium and calm.

---

# Button System

Buttons should feel:

- premium
- restrained
- balanced
- modern

Rules:
- consistent height
- consistent padding
- subtle hover transitions
- refined interaction feel

Avoid:
- oversized buttons
- flashy hover effects
- glowing borders
- aggressive animations

---

# Card & Surface System

Cards and surfaces should:

- feel clean
- maintain spacing consistency
- use restrained depth

Use:
- subtle borders
- minimal shadows
- clean separation

Avoid:
- glassmorphism overload
- floating neon effects
- SaaS dashboard aesthetics

---

# Image Composition

Vehicle imagery is the hero element.

Rules:
- never crop vehicles awkwardly
- preserve realistic lighting
- maintain cinematic composition
- keep UI secondary to vehicle imagery

Images should feel:
- premium
- realistic
- spacious
- intentional

Avoid clutter around vehicle visuals.

---

# Animation Philosophy

Animations should feel:

- smooth
- cinematic
- refined
- subtle

Preferred motion:
- fade
- slight upward translate
- smooth easing
- restrained stagger effects

Avoid:
- bounce animations
- exaggerated scaling
- fast aggressive movement
- distracting motion

Animations should support the experience, not dominate it.

---

# Responsive Philosophy

Responsive layouts must feel intentionally designed.

Do NOT simply stack desktop sections.

Mobile layouts should:
- preserve hierarchy
- maintain spacing rhythm
- feel premium
- avoid clutter
- maintain visual breathing room

Tablet layouts should also feel refined and balanced.

---

# UI Refinement Priorities

Priority order:

1. spacing consistency
2. typography hierarchy
3. visual balance
4. section rhythm
5. image composition
6. responsiveness
7. button consistency
8. animation refinement

---

# UX Priorities

Highest priorities:

- clarity
- premium perception
- smooth navigation
- readability
- consistency
- restraint
- hierarchy

---

# Do

- refine spacing
- improve visual rhythm
- improve typography hierarchy
- improve alignment
- improve responsiveness
- improve section balance
- maintain premium feel
- maintain cinematic presentation

---

# Do Not

- redesign the website
- change branding
- add random sections
- overdesign layouts
- convert into SaaS UI
- overuse gradients
- overuse shadows
- overcrowd sections
- use trendy effects excessively

---

# Final Goal

The final website should feel like a professionally art-directed international automotive website rather than an AI-generated template recreation.

The website should feel polished, premium, restrained, cinematic, and globally competitive while preserving the original brand identity and structure.
